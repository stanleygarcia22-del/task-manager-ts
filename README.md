# 📋 Task Manager - TypeScript Vanilla & Vite

Sistema de Gestión de Tareas interactivo, responsive y con persistencia de datos, desarrollado con **TypeScript vanilla**, **Vite**, HTML5 y CSS3 aplicando principios de **Clean Architecture**.

## 🚀 Características

- **CRUD Completo:** Crear, visualizar, editar, eliminar y cambiar el estado de las tareas.
- **Persistencia Local:** Los datos se sincronizan automáticamente en `localStorage`.
- **Filtros Avanzados y Búsqueda:** Filtrado dinámico por estado (completada/pendiente), prioridad (alta, media, baja) y buscador por título.
- **Diseño Responsive:** Adaptable a dispositivos móviles y de escritorio mediante CSS Grid/Flexbox.
- **Tipado Estricto:** Implementación de interfaces y tipos fuertemente tipados en TypeScript sin frameworks de UI.

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** TypeScript / JavaScript (ES6+)
- **Bundler:** Vite
- **Estilos:** CSS3 puro con variables CSS
- **Persistencia:** Web Storage API (`localStorage`)
